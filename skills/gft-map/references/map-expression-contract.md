# GFT Map 表达约定

约定版本：2026-10-11.5。

一份思考需要让你看清已经理解了什么、还有什么问题，以及以后从哪里继续。Map 用节点和连线呈现主要思路，Doc 把理由、例子和条件连续讲清楚。你可以先读正文，也可以从一个关心的节点进入。

以下三条约定说明这份内容怎样组织，也帮助你判断一次修改是否让它变得更好。

## Map 帮助定位思路 Doc 负责连续解释

Map 让你辨认关键要点、尚未解决的问题及它们之间的承接；节点展开提供这一点的简短说明。Doc 把多个要点组织成连续的解释，容纳背景、例子、条件和过渡。普通正文无需每段都变成节点。

两种视图中的同一要点应当能互相定位，标题、判断状态和关键含义保持一致。节点短说明与章节正文可以有不同篇幅；修改观点或适用条件时，要检查相关表述是否仍然一致。两种阅读方式都应能找到自己需要的解释。

## 节点表达一个具体要点或问题

节点值得让人单独停下来理解、引用或继续讨论。标题应当指出具体意思，展开说明理由和必要条件。

例如，“交易成本”只是一个话题；“使用市场也要付成本”表达了一个要点。展开后再说明：寻找合作对象、了解报价、商谈条件都会耗费资源。这些例子可以放在同一个节点里。

一个节点有多大，取决于它承担的理解任务。同一观点的例子和补充通常留在原处；内容相近却回答不同问题时，也可以分别成点。无须把每句话都做成节点。

问题尚未解决，就保留为问题。推断需要条件，就把条件讲清楚。一项想法进入脉络，不代表它已经被你采纳。

## 连线表示思路的承接

A 指向 B，表示可以沿着 A 继续理解 B。二者怎样承接，应当能在内容中找到解释：B 可能回答 A 引出的问题、补上一个条件、提出反例，或者把已有方法用于新问题。

例如，“内部组织也会付代价”接到“边界要看下一项交易”：既然内部也有成本，就需要比较，再加入这项工作时，内部安排与外部合作各要付出什么。

承接说明归属于这条关系，只维护一份。在下游节点正文前引用展示，说明怎样从来源节点到这里；节点内部只呈现一句可编辑的关联说明，通常 16–24 字，最多 32 字；只保留怎样从前一点到这里，详细解释留给节点或 Doc，不重复展示来源节点标题或方向标签；来源端点通过地图中的连线辨认。节点末尾不展示下游去向，避免把未来探索写成既定路线。点线可直接进入承接节点，避免多出一层说明窗口。

仅仅先后出现、用词相似，不足以连线。连线也不自动表示因果或证明；具体论证仍要看说明与正文。独立节点可以不连线，图中也不必画出全部关联。

## 演变应当让理解更清楚

后续讨论可能把原来的话讲得更明白，补充条件，形成新观点，也可能推翻原有判断。修改应当让这些变化进入合适的位置，并让 Map、节点说明和 Doc 保持一致。

例如，在“先约定职责，再安排具体工作”里补上剪辑师的例子，是把同一件事解释清楚；把成本比较用于“AI 会怎样改变团队”，则带来了新的应用，值得考虑独立呈现。如果结论依赖假设，这个边界也要跟着保留。

评价一次变化，可以看三件事：

- **更清楚了什么？**是措辞、理由、条件，还是一个新的认识？
- **为什么放在这里？**它在补充原有理解，还是带来了值得单独讨论的问题？
- **整体还能读通吗？**新旧内容是否一致，已经改变的判断是否仍被当成当前结论？

好的变化应让读者直接感到信息更完备、思路更清晰、关系更流畅。仍成立的依据、例子和边界应保留，新的区别应进入合适位置，额外阅读应当换来理解收益。操作历史与可撤回快照保障控制，不需要每次另外读一篇演变解说。

节点可以增加、减少，也可以保持不变。没有相关的新内容时，无须为了更新而改动。

## 编辑时怎样使用这些约定

下面把常见情况对应到编辑动作和完成条件，可在需要时查阅。

| 遇到的情况 | 可以怎样处理 | 怎样检查完成 |
| --- | --- | --- |
| 同一个要点需要例子或更清楚的解释 | 补充原节点说明及相关正文。 | 仍在回答原来的问题，解释与标题相符，没有只因换一种说法而重复立点。 |
| 出现值得单独继续讨论的新要点或问题 | 可以新增节点，放进相应章节；有明确承接依据时再连线。 | 能指出它比现有内容多回答或多提出了什么；普通追问不必逐次立点，尚未确定的部分仍然明确。 |
| 两个节点需要连接 | 在已有内容中确认承接依据，必要时把桥梁补入说明，再建立连接。 | 读者能从内容看出 B 如何接着 A；只有先后顺序或话题相似时，保持不连。 |
| 新条件或证据改变了原判断 | 修正当前判断和受影响的正文，说明改变的条件或理由。 | 标题、节点说明与 Doc 不互相矛盾；尚未解决的部分仍保留。提出反例但还不能确定推翻时，先保留分歧。 |

例如，给“先约定职责，再安排具体工作”增加剪辑师的例子，完成条件是让读者看清哪些调整属于约定范围。如果新材料表明某项调整超出职责，就要同时修改适用范围，不能只往说明末尾追加一句。

拆分或合并有多个合理答案时，优先保留已有清楚的表达。改变结构需要能说明理解上的收益；暂时拿不准，也可以先保留问题或分歧。

这些约定用于阅读、编辑和评价思考产物。无论内容由人还是 AI 写入，都应接受同样的检查；AI 的一次生成并不保证已经满足这些要求。

## 地图中的选取和操作

悬停只高亮当前节点或线段，不高亮关联元素，不压淡其它内容。节点下方保留悬停工具栏，线段不出悬停菜单。单击选取节点或线段，并打开相关说明；Ctrl／Cmd 点击可加选，Shift 拖动可框选。选中元素后，上方“重画”旁显示“删除”，多选不另出操作弹窗。节点正文卡片不承担画布拖动。节点内的关系区域与外面的连线共享选中状态；点击图标或留白可选线，文字仍直接可编辑，同时选中对应的线。本地节点的整理使用同一图文规范，只允许改该节点及相关章节，等待标记跟随实际提交的范围，不跟着后来的选区移动。说明里可以直接编辑文字；清空关系说明不等于删除连线。删除可用上方按钮或 Delete / Backspace，不影响文本输入框内的删字。删除连线不删除两端节点；一次多选删除可一次撤回，内容变更也可通过持久化操作历史撤回。
