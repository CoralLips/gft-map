详细安装与启动说明

第一次，不必先想好所有规则。

  1. 新建脉络，连接一场聊天。选择已有内容，第一次更新会生成主题和图文。
  2. 看看它理解对了没有。在 Doc 直接修改。主题就是过滤范围，可以边用边调整。

开始之前，你可能想知道。

这和保存聊天记录有什么不同？

聊天按时间展开，GFT Map 围绕一件事维护当前理解：决定、理由、疑问和它们的关系。已接收的来源保留在 Log 中，Doc 和 Map 根据主题组织。你可以直接纠正这份理解。

Agent 会自动知道右侧每一次修改吗？

不会。GFT Map 维护当前索引和正文，由 Agent 根据任务按需读取。网页连接成功不等于记忆已经进入聊天；你可以明确让 Agent 读取，检查它是否采用最新修正。

我的聊天会上传到 GFT 吗？

本地主题不会自动上传 GFT，也不要求登录。点击模型操作时，处理所需材料会交给你配置的 Agent 执行器及其模型服务，使用它的额度。本地存储不等于离线模型。

Codex 和 Claude Code 都能用吗？

两者的聊天来源已适配，安装和本地面板可用。Codex 执行已真实验收；Claude ACP 执行和跨客户端续接仍为实验性。也可用 Codex 执行器处理所选 Claude Code 聊天。

可以直接把在线样例变成我的项目吗？

可以。从示例里导出完整脉络包，在本地版导入，再修改主题和内容。样例不带你本机的连接关系或读取进度。
